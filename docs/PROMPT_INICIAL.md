# Prompt inicial para Claude Code

Leia integralmente o arquivo `CLAUDE.md` e use-o como especificação principal do projeto **ArTermo — Propriedades do Ar**.

Quero que você desenvolva o aplicativo nesta pasta, pronto para executar localmente no meu computador e publicar posteriormente pelo GitHub. O aplicativo será uma PWA responsiva e instalável no celular.

Comece avaliando o ambiente e a pasta atual. Depois implemente o projeto em etapas, seguindo o plano e os critérios de aceite do `CLAUDE.md`. Não se limite a apresentar um planejamento: crie os arquivos, escreva o código, rode os testes e faça o build. Não apague arquivos preexistentes sem necessidade.

Prioridades absolutas:
1. Cálculos corretos e testados: conversão de unidades, interpolação linear por referência e média aritmética das fontes.
2. Cadastro e edição independente das tabelas Kreith, Incropera e Çengel, com metadados de edição/página/pressão.
3. Consulta individual, comparação lado a lado e média das três referências.
4. Importação CSV, backup JSON e funcionamento offline.
5. Interface confortável no celular e no computador.

Não invente nenhum valor dos livros. Comece com as três referências cadastradas, mas com tabelas vazias. Caso precise de dados para demonstrar a interface ou testar cálculos, use apenas valores sintéticos claramente identificados como dados fictícios de teste.

Antes de finalizar, execute todos os testes disponíveis e o build de produção. Corrija os problemas encontrados e atualize o README com os comandos exatos para instalar dependências, iniciar em modo desenvolvimento, testar e gerar a versão de produção.

Ao terminar, apresente um resumo do que foi criado, a estrutura principal de pastas, os comandos para executar e como instalar a PWA no celular.
